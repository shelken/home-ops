# 重建后检查与自动化状态

当前重建集群后无需手动介入配置，均已纳入自动化交付与配置管理。

## 节点标签（已全自动化）

GPU 与存储标签已全部由 nix-config 声明：各节点 `hosts/k8s/<节点>/default.nix` 的 `shelken.k3s.nodeLabels` 写进 k3s 配置，节点重装后自动恢复，无需人工执行 `kubectl label`（包括 `nvidia.com/gpu.present`、`intel.feature.node.kubernetes.io/gpu` 与 `node.longhorn.io/create-default-disk`）。

重建后验证命令：

```bash
kubectl get nodes -L nvidia.com/gpu.present,intel.feature.node.kubernetes.io/gpu,node.longhorn.io/create-default-disk
```

## Multus 网络缓存

Multus CNI 配置由 Flux 交付的 Multus chart（`k8s/infra/common/network/multus/app/`）在节点生成。节点重装是全新系统，不会残留旧的 `/etc/cni/net.d/*multus*` 配置，无需手动清理
