# 部署 k3s

## Ansible 主部署路径

集群部署与节点维护统一使用 Ansible：

```bash
task bootstrap
# 或单独执行：ansible-playbook ansible/playbooks/install-k3s.yaml
```


## 历史存档（k3sup）

> 当前生产环境统一由 Ansible 管理，以下 k3sup 命令仅作历史操作存档

### 组建单控制节点

```bash
# 需本机已安装 k3sup（存档步骤，当前主路径是 ansible）

# --embedded-registry 目前为 false；镜像加速走 /etc/rancher/k3s/registries.yaml（ansible/playbooks/tasks/k3s-registry.yaml）
# ref: https://docs.k3s.io/installation/registry-mirror
# 版本定义以 ansible/inventory/group_vars/all.yml 的 k3s_release_version 为准
K3S_VERSION=$(yq '.k3s_release_version' ansible/inventory/group_vars/all.yml)
# --disable local-storage
# 使用openebs的localpv

export SSH_USER="<SSH_USER>"
export SSH_PRIVATE_KEY_PATH="<SSH_PRIVATE_KEY_PATH>"

# 主节点
k3sup install --user "$SSH_USER" --ip 192.168.6.80 \
  --k3s-extra-args "--disable traefik --disable servicelb --flannel-backend=none --disable-network-policy --disable-kube-proxy --disable local-storage --disable coredns --disable metrics-server" \
  --k3s-version "$K3S_VERSION" \
  --ssh-key "$SSH_PRIVATE_KEY_PATH"

# 加入 agent（worker）
k3sup join \
    --user "$SSH_USER" \
    --ip 192.168.6.111 \
    --server-ip 192.168.6.80 \
    --server-user "$SSH_USER" \
    --k3s-version "$K3S_VERSION" \
    --ssh-key "$SSH_PRIVATE_KEY_PATH"

# free-network (optional)
scripts/free-networks.sh <SSH_HOST> <PROXY_IP> [PROXY_PORT]

```

### HA 嵌入式etcd 集群

```bash

k3sup install --user "$SSH_USER" --ip 192.168.6.110 --cluster \
  --k3s-extra-args "--disable traefik --disable servicelb --flannel-backend=none --disable-network-policy --disable-kube-proxy --disable local-storage --disable coredns --disable metrics-server" \
  --ssh-key "$SSH_PRIVATE_KEY_PATH"

# 加入控制平面
k3sup join \
    --user "$SSH_USER" \
    --ip 192.168.6.111 \
    --server-ip 192.168.6.110 \
    --server-user "$SSH_USER" \
    --server \
    --k3s-extra-args "--disable traefik --disable servicelb --flannel-backend=none --disable-network-policy --disable-kube-proxy --disable local-storage --disable coredns --disable metrics-server" \
    --ssh-key "$SSH_PRIVATE_KEY_PATH"

```

## 节点维护

### 驱逐与移除节点

```bash
kubectl drain <agentNodeName> --ignore-daemonsets --delete-emptydir-data
kubectl delete node <agentNodeName>
```

### 卸载说明

卸载 k3s 需在目标节点执行官方卸载脚本或对应 Playbook：

1. 工作节点（Agent）：

```bash
/usr/local/bin/k3s-agent-uninstall.sh
ansible-playbook ansible/playbooks/delete-k3s.yml
```

2. 控制平面节点（Server）：

```bash
/usr/local/bin/k3s-uninstall.sh
ansible-playbook ansible/playbooks/delete-k3s.yml
```

注意：

- 卸载脚本会停止所有 k3s 进程
- 删除 k3s 相关配置文件与持久化数据目录
- 清理 iptables 规则与 IPVS 映射表
- 移除 k3s 创建的虚拟网络接口
