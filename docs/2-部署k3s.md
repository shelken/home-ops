# 部署 k3s

节点是 NixOS，系统与 k3s 由 nix-config 声明，部署、重装、升级流程见 nix-config 的 `hosts/k8s/README.md`，决策见 [ADR-0011](adr/0011-k8s-nodes-declared-in-nix-config.md)。本仓库只管集群内的 GitOps

## 节点维护

### 驱逐与移除节点

```bash
kubectl drain <agentNodeName> --ignore-daemonsets --delete-emptydir-data
kubectl delete node <agentNodeName>
```

重装节点前后的 drain、回滚点与恢复步骤见 nix-config 的 `hosts/k8s/README.md`
