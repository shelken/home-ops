# 重建后需要手动的操作

## 节点标签（已全自动化）

GPU 与存储标签已全部由 Ansible 声明式管理：`ansible/inventory/host_vars/homelab-1.yaml` 的 `k3s_node_labels` 由 `group_vars/workers` 渲染进 k3s 节点配置，节点重建后 `install-k3s` 自动恢复，无需人工执行 `kubectl label`（包括 `nvidia.com/gpu.present`、`intel.feature.node.kubernetes.io/gpu` 与 `node.longhorn.io/create-default-disk`）

## Multus 网络缓存

节点重建后 Multus CNI 配置由 Ansible 初始化自动生成，无残留缓存，无需手动清理
